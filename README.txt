PREVIEW
Open index.html in a modern browser. For best results, use VS Code Live Server or any local static server.

VERCEL DEPLOYMENT
1. Upload all files and the assets folder to a GitHub repository.
2. Go to https://vercel.com/new and import the repository.
3. Framework preset: Other
4. Build command: leave blank
5. Output directory: . (or leave default if Vercel detects static files)
6. Deploy.
